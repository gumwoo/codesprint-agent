# ADR-0026 · 힌트 사다리는 문제 데이터가 갖는다

- 상태: 채택
- 날짜: 2026-09-13
- 정본 근거: PRD §73(Hint System) · §74(힌트 의존도), Addendum §22,
  [ADR-0012](0012-curriculum-is-packaged-from-one-source.md),
  [ADR-0024](0024-review-concept-resolves-to-curriculum-material.md)

## 맥락

이 저장소는 **힌트 기능이 없는데도 힌트 사용량으로 mastery 를 깎고 있었다.** 제출
API 가 `hintLevel` 과 `solutionViewed` 를 받았고, Evidence 는 그 값으로 독립 풀이
여부를 갈랐다. PR #19 에서 입력 경로를 막아(0 / false 만 허용) 그 구멍을 닫았지만,
**산식과 컬럼과 golden 은 그대로 두었다** — 힌트가 생기면 쓰려고.

이제 그것을 만든다. 먼저 정할 것은 하나다 — **힌트 내용이 어디서 오는가.**

PRD 는 Hint Agent(LLM)로 그렸다. 그런데 이 저장소에서 LLM 은 **기본이 꺼져 있다.**
그대로 옮기면 CI 도 데모도 힌트를 볼 수 없고, 힌트 의존도를 재는 길이 열리지 않는다.
ADR-0024 에서 `REVIEW_CONCEPT` 가 같은 문제를 만났고, 자료를 커리큘럼 데이터로
옮겨 풀었다.

## 결정

**H1~H5 는 `problems/<CODE>/hints.yaml` 에 둔다.** 문제마다 하나씩이고, CI 가 검증한다.

```
H1 문제 관찰 포인트
H2 알고리즘 범주
H3 자료구조 · 상태
H4 핵심 전이
H5 의사코드
H6 전체 풀이        <- 여기 없다
```

### H6 은 `reference.py` 다

사다리의 마지막 칸은 이미 저장소에 있다. 복사본을 만들지 않는다(ADR-0012) —
두 곳에 적으면 한쪽만 고쳐진 날 **사용자가 틀린 풀이를 본다.** 그리고 그 어긋남은
CI 가 정답을 채점할 때도 드러나지 않는다. 채점은 `reference.py` 만 보기 때문이다.

### 검사는 "사다리가 실제로 사다리인가" 를 본다

힌트 의존도는 **몇 단계를 봤는가로 mastery 를 가른다**(Addendum §22, `AC_BY_HINT`).
그 숫자가 뜻을 가지려면 모든 문제에서 같은 것을 가리켜야 한다.

```
단계가 1..5 로 다 있는가        빠지면 건너뛴 사용자의 의존도가 실제보다 낮게 기록된다
같은 힌트가 두 번 있는가        두 칸이 붙으면 그 사이 단계는 아무것도 주지 않는다
정답 코드를 그대로 담았는가      H5 가 곧 H6 이면 "해설을 봤다" 와 같은 값을 받는다
다른 문제에서 복사했는가        내용이 그 문제를 가리키지 않으면 사다리가 아니다
```

**마지막에서 두 번째가 실제로 잡았다.** 이 ADR 을 쓰면서 만든 P04 의 힌트가
`reference.py` 의 한 줄을 그대로 담고 있었고, 검사를 붙이자마자 걸렸다.

`tools/meta_test_problems.py` 에 다섯 개를 깨뜨리는 케이스를 함께 넣었다 —
검사가 통과하는 것과 검사가 일하는 것은 다르다.

## 무엇을 정하지 않았는가

**LLM 을 배제하지 않는다.** 사다리가 데이터로 있으면, 나중에 LLM 이 그것을
사용자 코드에 맞춰 다듬는 자리가 생긴다. 그때도 경계는 그대로다.

```
LLM 이 만드는 것    힌트 내용
시스템이 정하는 것   몇 단계를 봤는가   <- 서버가 내주면서 남긴 기록에서
```

Reviewer 에서 "confidence 는 LLM 이, 확정은 시스템이" 로 그은 선과 같다(ADR-0001).

**이 PR 은 데이터와 검사까지다.** 서버가 힌트를 내주고 기록하는 것, 제출이 그
기록에서 단계를 읽는 것, 화면은 뒤따른다 — 나누는 이유는 각각 되돌릴 수 있어야
하기 때문이다.

## 결과

- 문제 15개가 각각 5단계 힌트를 갖는다. `hints.yaml` 이 없으면 CI 가 막는다
- 힌트 의존도 산식(`AC_BY_HINT`)이 처음으로 실재하는 입력을 갖게 될 준비가 됐다
- 아직 **아무도 힌트를 볼 수 없다.** 데이터만 있고 내주는 길이 없다
